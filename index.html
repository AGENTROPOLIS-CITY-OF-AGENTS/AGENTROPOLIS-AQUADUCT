AQUEDUCT UTILITY PROTOCOL

Agent service path.

01

DISCOVER

Resolve the agent wallet, requested chain family, target test network, and nearest approved Chainwell capability.

02

MEASURE

Read testnet balance and compare against bounded target, minimum threshold, cooldown, and provider policy.

03

AUTHORIZE

FLOWKEEPER requests scoped authority through the Rust trust boundary. Raw seeds and private keys never enter model context.

04

SERVICE

AQUEDUCT MCP routes the request to the correct Chainwell and chain adapter without giving the browser execution authority.

05

VERIFY

Confirm the test asset arrived and correlate provider, transaction, wallet-registry, and policy evidence.

06

RECEIPT

Emit durable evidence with network, wallet ID, source, amount, timestamp, BE decision, and verification state.
