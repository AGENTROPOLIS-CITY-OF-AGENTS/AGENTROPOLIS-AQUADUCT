AQUEDUCT PROTOCOL

Governed execution path.

01

DISCOVER

Resolve chain family, wallet class, test network, provider mode, and current registry state.

02

MEASURE

Read balance and compare against bounded target, minimum threshold, cooldown, and provider policy.

03

AUTHORIZE

FLOWKEEPER requests scoped authority. Raw seeds and private keys never enter model context.

04

ROUTE

AQUEDUCT MCP exposes a stable interface while the Agent Kit selects the correct chain adapter.

05

VERIFY

Confirm the test asset landed and correlate provider, transaction, and wallet registry evidence.

06

RECEIPT

Emit durable evidence with network, wallet ID, source, amount, timestamp, policy decision, and state.
