Aqueduct protocol

Visual today. Governed execution next.

01

Discover

Read the chain registry and resolve the correct wallet family, test network, faucet source, and current provider mode.

02

Measure

Check test-wallet balance and compare it against a bounded target, minimum threshold, cooldown, and provider policy.

03

Authorize

FLOWKEEPER requests scoped authority through AGENTROPOLIS governance. No raw seed phrase or private key enters model context.

04

Route

The Agent Kit selects the chain adapter. MCP exposes one stable interface while chain-specific mechanics stay behind the grid.

05

Verify

Confirm the test asset landed, capture the transaction or provider receipt, and update the wallet registry state.

06

Receipt

Emit auditable evidence with network, wallet ID, amount, source, timestamp, policy decision, and verification state.
